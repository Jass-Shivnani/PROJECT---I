Motivation & Problem Definition
Bridging the "Actuation Gap" in AI Assistants
⚠️ The Actuation Gap in Current Systems
  • Passive Text Generation Silos: Mainstream LLMs (ChatGPT, Claude) only answer queries; they cannot execute actions directly on the user's desktop.
  • Cloud Privacy Exposure: Cloud agentic platforms (OpenAI Operator, AutoGPT) transmit local files, emails, and tokens to third-party servers.
  • Context Window Bloat: Flat vector RAG dumps entire raw file chunks, causing context overflow and high inference costs.
🎯 Proposed Dione Solution
  • 100% Local Inference: Runs on consumer PC hardware with zero external cloud dependencies.
  • Closed-Loop ReAct Micro-Kernel: Interleaves reasoning and tool calling with deterministic step budgets.
  • Typed Relational Knowledge Graph: NetworkX graph extraction achieving ~75% token reduction and sub-2ms lookups.
  • Ambient Proactivity: Adaptive background heartbeat with 1-click proposal cards.
