Google Stitch Prompt — Agno Agent-UI Design

Create a dark-mode AI Agent interface modeled after the open-source "agno-agi/agent-ui" (Agno AgentOS UI) built with Next.js, shadcn/ui, Geist/Inter sans font, and DM Mono uppercase labels:

1. Color Palette & Typography:
   - Main background: #111113; Left Sidebar & Drawer background: #161618; Elevated inputs/cards: #1F1F23 with subtle 1px solid rgba(255,255,255,0.08) borders and rounded-xl corners.
   - Brand accent: Agno Flame Orange (#FF4017) icon badge, Emerald (#22C55E) live endpoint status dot, and crisp solid White (#FAFAFA) primary CTA buttons with dark #111113 text.
   - All section headers, tool call pills, and badges use uppercase DM Mono (font-mono text-[10px] tracking-[0.12em]).

2. Left Sidebar (272px width, collapsible):
   - Header: Flame orange square logo + "AGENT UI" in tracked uppercase monospace + collapse icon.
   - Primary CTA: Full-width solid white "+ NEW CHAT" rounded-xl button.
   - ENDPOINT box: Dark rounded-xl field showing "http://localhost:8900" with a pulsing green dot, edit pencil icon, and refresh icon.
   - AI STUDIO API KEY box: Masked token input for Google AI Studio keys.
   - MODE toggle: Segmented switcher between "Team" (Multi-Agent Orchestrator) and "Agent" (Single Agent).
   - TEAM / AGENT & MODEL selector: Dropdown for "Dione Orchestrator Team (5 Agents)" paired with model badges for "VOICE LIVE: gemini-2.5-flash-live" and "BG WORKER: gemini-3.8-flash".
   - SESSIONS list: Clean scrollable list of saved sessions with hover delete icon.

3. Center Chat & Agent Execution Stream (max-w-3xl centered):
   - Agent responses display three signature Agno components above the markdown text:
     (a) Collapsible "Reasoning" accordion showing step-by-step multi-agent delegation thoughts and latency (e.g., Supervisor -> SafetyAuditor -> KnowledgeGraph -> ComputerUseOperator).
     (b) Inline horizontal row of rounded-full monospace "Tool Calls" pills (e.g., `computer_switch_audio_device`, `computer_click_coords`, `allocate_knapsack_context`) that expand to show JSON arguments and outputs when clicked.
     (c) Collapsible "References" chips showing Knowledge Graph dossiers and sources.
   - Bottom Floating Input Bar: Rounded-2xl dark container (#18181B) with auto-expanding "Ask anything..." textarea, a live Gemini Live Voice waveform + "Talk" mic button, quick action chips, and a solid white upward-arrow send button.

4. Right Slide-Over Computer-Use Viewport Drawer:
   - Live 16:9 desktop screen preview with Windows UIA bounding boxes, animated virtual cursor, (X, Y) coordinate clicker, and a 1-Click Approval Gate card.
